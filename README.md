# AD-HTC-fuel-Enhanced-Gas-Cycle
This project is an AD-HTC Fuel-Enhanced Gas Power Cycle simulator. It converts wet and dry biomass into energy through two paths: Anaerobic Digestion for biogas and Hydrothermal Carbonization for fuel enhancement. The code calculates thermodynamic states (h,s) and generates T-s/h-s diagrams to optimize power delivery to building envelopes.
